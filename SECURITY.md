# Security

Please do not publish secrets, credentials, private prompts, personal data, or third-party confidential material in issues, pull requests, fixtures, or receipts.

For experiments involving tools or external systems:
- use test accounts and disposable fixtures
- minimize permissions
- distinguish capability from authorization
- do not create unauthorized external communication channels
- redact sensitive receipts before publication

If a finding itself could enable abuse, describe the behavior at the minimum level needed for reproducibility and avoid publishing operational exploit details.
