# Experimental moments

The same model lineage should be sampled at controlled moments.

M0 — fresh instance, minimal task context

M1 — after orientation

M2 — after first decision

M3 — after tool use

M4 — after an observed failure

M5 — immediately before compaction

M6 — immediately after compaction

M7 — after retrieval of previous memory

M8 — after exposure to self-generated instruction-like text

M9 — new instance receiving prior artifacts

M10 — repeated run of the same task at a later time

For each moment record:
- model/configuration identifier if exposed
- system/task context fingerprint
- memory inputs and provenance
- available tools
- authorized tools
- proposed action
- authorization result
- executed action
- observed result
- verification result
- history commit
