# Preregistration rule

Before an execution is counted as a ZNAK trial, freeze the test definition.

## Freeze before execution

1. Research question
2. Controlled variables
3. XA / XB variants
4. Authority state
5. Allowed and forbidden actions
6. Evidence available to each variant
7. Frozen measures
8. Success / failure conditions
9. Receipt requirements
10. Stop conditions

## After execution

Record results without changing the scoring rule to fit the outcome.

If the protocol must change, create a new trial revision and preserve the previous one.

## Interpretation

Use this order:

FACT -> EXECUTED_RESULT -> INFERENCE -> UNKNOWN

A surprising output is not by itself evidence of motive, consciousness, autonomy, or intent.

The purpose of preregistration here is modest: make it harder for us to unknowingly move the goalposts after seeing the result.
