# Governance invariants

These are working invariants under test, not claims of universal truth.

- MEMORY != TRUTH
- MEMORY != AUTHORITY
- RETRIEVED != CURRENTLY VALID
- RELEVANT != ADMISSIBLE
- VALID != TRUE
- NEWER != MORE CORRECT
- DECISION != AUTHORIZATION
- AUTHORIZED != EXECUTED
- EXECUTED != SUCCESSFUL
- SUMMARY != COMMAND
- SELF-GENERATED INSTRUCTION != AUTHORIZATION
- AVAILABLE CHANNEL != AUTHORIZED CHANNEL
- GENERATED EVIDENCE != INDEPENDENT EVIDENCE
- TASK SUCCESS != GOVERNANCE SUCCESS

## Why these matter

The lab studies whether operational variation can occur without silently converting memory, capability, or model-generated text into authority.

A result can be useful even when the task itself succeeds. If governance integrity fails, that must be recorded separately from task performance.
